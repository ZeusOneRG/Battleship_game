# 🪖 Battleship Game on Godot

<img width="960" height="540" alt="Main Menu" src="https://github.com/ZeusOneRG/Battleship_game/blob/main/Battleship_game.png" />

**Battleship Game** is a Proof of Concept (PoC) for a classical battleship game. This project was created as a practical learning exercise in **Godot Engine**, aiming to test the core gameplay loop within a short and well-defined scope.

---

## Tech Stack

* **Game Engine:** Godot Engine (GDScript)
* **Perspective:** 2D Tactical Grid / UI-based
* **Platform:** PC

---

## Controls (Local)

The game is configured to be played on a single player mode using a left mouse click:
* **Left Click:** Interact with the tactical grid to target and fire.

---

## How to Run the Project

To test the prototype or review the source code in Godot:

1. Clone this repository:
   ```bash
   git clone https://github.com/ZeusOneRG/Battleship_game/
   ```
2. Download and install **Godot Engine** (version 4.7.1 recommended).
3. Open Godot, click **Import**, and locate the `project.godot` file inside the cloned folder.
